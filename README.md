# Pico2_Flightcontrols
A USB HID joystick for the Raspberry Pi Pico 2 W (RP2350), written in C with the Pico SDK and TinyUSB.

## WORK IN PROGRESS
This is a very much work in progress. Things are untested, incomplete, and likely to change or break without notice.

##Features
- [x] Basic X/Y axes and 8 buttons
- [x] Centre calibration and deadzone
- [ ] Hat switch / D-pad
- [ ] Additional axes (e.g. collective)
- [ ] Persistent calibration
